## 시안 A · 에디토리얼 럭셔리

**예시 브랜드**: 온율 — 제주 유기농 비건 스킨케어
**적합 분야**: 뷰티, 라이프스타일, 공간·숙박, 파인다이닝, 공예 브랜드

### 느낌
종이 질감의 따뜻한 고급감. 여백으로 읽는 속도를 늦추는 톤. 정보를 밀어 넣지 않고 덜어내는 쪽으로 설계했습니다.

### 컬러
- 바탕 웜 아이보리 `#FDFBF7`
- 본문 에스프레소 `#2A211B`
- 보조 `#7A6B5F`
- 면 `#F3EEE4`
- 액센트 세이지 `#6B7A5E`

### 타이포
- 국문 디스플레이: Gowun Batang
- 라틴 · 숫자 · 구두점: Instrument Serif
- 본문: Gowun Dodum
- 헤드라인 104px / line-height 1.02 / letter-spacing −0.035em

### 레이아웃
에디토리얼 스플릿. 좌측에 대형 세리프 헤드라인과 지표 3개, 우측에 아치형(220px) 제품 프레임. 제품 섹션은 3열 카드이며 마지막 카드만 반전(다크)시켜 시선을 잡습니다.

### 디테일
- 필름 그레인 오버레이 3.5%
- 상단 플로팅 필 내비게이션 (전체 폭 고정 바 아님)
- CTA는 버튼 안에 원형 아이콘을 품은 중첩 구조
- 성분표는 1px 헤어라인 4열 그리드

## 시안 B · 유틸리테리언 미니멀

**예시 브랜드**: LEDGER — 이커머스 정산 자동화 SaaS
**적합 분야**: B2B SaaS, 핀테크, 개발자 도구, 데이터 대시보드, 내부 관리 도구

### 느낌
문서처럼 조용하고 정확한 화면. 장식 대신 정보 밀도로 신뢰를 만듭니다. 그라디언트와 그림자를 쓰지 않습니다.

### 컬러
- 바탕 웜 본 `#F7F6F3`
- 카드 `#FFFFFF` / `#FBFBFA`
- 본문 `#111111`
- 보조 `#787774`
- 경계선 `#EAEAEA`
- 파스텔 스팟: 청 `#E1F3FE`/`#1F6C9F` · 녹 `#EDF3EC`/`#346538` · 황 `#FBF3DB`/`#956400` · 적 `#FDEBEC`/`#9F2F2D`

### 타이포
- 헤드라인: Noto Serif KR 58px / −0.035em
- UI · 본문: IBM Plex Sans KR
- 수치 · 메타: JetBrains Mono

### 레이아웃
비대칭 벤토 그리드(3열 × 2행, 2칸 span 2개). 모든 경계는 예외 없이 1px `#EAEAEA`, 라운드는 6–12px로 고정. 히어로 우측은 macOS 창 크롬을 쓴 대시보드 목업.

### 디테일
- kbd 키캡으로 단축키 표기
- 파스텔 상태 배지(확정/대기)
- API 예시는 모노스페이스 블록
- FAQ는 컨테이너 없이 border-bottom과 +/− 토글만

- 경고 스트라이프(45° 반복 그라디언트), 바코드 라인
- 실측 리포트 테이블(측정값/공차/판정)로 제조업 신뢰를 표현

## 시스템에 반영할 때

세 시안은 다음 축에서만 달라지도록 설계했습니다. 자동 제작 시스템의 **스타일 토큰**으로 그대로 뽑아 쓸 수 있습니다.

1. **바탕 온도** — 웜 아이보리 / 웜 그레이 / 무표백 용지
2. **모서리 반경** — 곡률 강함 / 6–12px 고정 / 0px
3. **타이포 대비** — 세리프 초대형 / 세리프+산세리프 중간 / 헤비 산세리프 극대형
4. **액센트 개수** — 1개 / 4개(의미 구분용) / 1개
5. **경계 표현** — 거의 없음 / 1px 균일 / 1–2px 강조 + 그리드 헤어라인
6. **모션 강도** — 느린 페이드업 / 거의 없음 / 없음(정적)
