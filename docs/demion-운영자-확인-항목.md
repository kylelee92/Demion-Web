# demion 홈페이지 — 운영자가 정해야 할 항목

시안에서는 아래 내용을 **임의로 약속하지 않았습니다.** 정해지면 해당 위치를 채워주세요.

## 1. 서비스 조건 (홈페이지에는 아직 적지 않음)

| 항목 | 현재 시안의 처리 | 정해야 할 것 |
|---|---|---|
| 첫 디자인의 제공 범위 | “홈페이지 디자인 방향을 보여드립니다”까지만 표기 | 첫 화면만인지, 여러 화면인지, 데스크톱·모바일 모두인지 |
| ‘하루’의 산정 기준 | “첫 디자인을 확인하는 시점, 제작 완료 기간이 아님”이라고만 표기 | 접수 후 몇 시간 기준인지, 영업일/주말, 자료가 부족할 때의 처리 |
| 첫 디자인 비용 | 사이트에 “디자인을 먼저 보고, 마음에 들면 그때 결제하세요”로 표기 (무료라고는 쓰지 않음) | 첫 디자인이 마음에 들지 않을 때 비용이 전혀 없는지, 언제 얼마를 결제하는지 |
| 수정 횟수 | 언급 없음 | 첫 디자인 수정 가능 여부와 횟수 |
| 제작 비용 | “필요한 범위에 맞춰 견적을 안내드립니다.” | 견적 산정 기준을 공개할지 |
| 제작 기간 | 언급 없음 | 확정 후 제작 기간 안내 방식 |

## 2. 문의 접수 연결

- 문의 패널 항목: 이름·이메일·현재 홈페이지(선택)·레퍼런스 홈페이지(선택, 쉼표로 여러 개)·의뢰 내용.
- 제출 → `POST /api/inquiry` → `worker/index.js` → Cloudflare Email Routing으로 운영자 메일 발송. 답장하면 문의자 이메일로 간다(Reply-To).
- 받는 주소는 저장소에 넣지 않고 Cloudflare 대시보드 Secret `INQUIRY_TO`에 둔다. 보내는 주소 기본값 `inquiry@demion.co`(`INQUIRY_FROM`으로 변경 가능).
- 대시보드에서 필요한 설정: demion.co Email Routing 켜기 → 받는 주소(Destination address) 인증 → `demion-web` Secret `INQUIRY_TO` 등록.
- 설정이 빠져 있으면 서버가 503을 돌려주고 패널에 “문의 접수 설정이 아직 끝나지 않아 전송되지 않았습니다”가 표시된다. 성공한 것처럼 보이지 않는다.
- 스팸 방지: 숨은 입력칸(봇이 채우면 조용히 버림), 다른 사이트에서 보낸 요청 거절, 입력 길이 제한. 스팸이 늘면 Turnstile 추가 검토.
- 개인정보 수집·이용 동의(필수): 문의 패널 하단 안내(수집 항목·목적·보유 기간) + 체크박스, 서버에서도 동의 없으면 거절. **보유 기간 “문의 처리 완료 후 1년”은 임시값 — 운영자가 확정할 것** (index.html, worker/index.js 두 곳).

- 상호, 대표자명, 사업자등록번호, 통신판매업 신고번호, 사업장 주소
- 개인정보 처리방침 (폼에서 이름·이메일을 받으므로 사실상 필요), 이용약관 여부

푸터의 해당 위치에는 주석(`index.html`)만 남겨두었습니다.

## 4. 기타

- 도메인과 호스팅. 검토용이라 `noindex`가 걸려 있으니 **공개 시 `index.html`의 robots 메타 줄을 지워야 합니다.**
- 선택작은 실제 작업 1점(조희욱)과 자체 콘셉트 2점(GW컨설팅, Precision Works)입니다. Precision Works는 가상 기업이며 실제 기업 정보를 넣지 않습니다. 실제 고객 작업이 생기면 고객 동의를 받은 뒤 교체하세요.

## 5. 다국어

- 한국어·영어·일본어를 지원합니다. 번역은 `sites/demion/i18n.js`의 표 한 곳에서 관리합니다. 문구를 고칠 때는 HTML의 한국어와 표의 원문을 함께 고치세요.
- 언어는 `?lang=en`처럼 주소로 지정할 수 있고, 고른 언어는 브라우저에 저장됩니다. 처음 방문하면 브라우저 언어를 따르며, 한국어·일본어가 아니면 영어로 표시합니다.
- **확인 필요:** 조희욱 작가의 영문·일본어 표기(Cho Hee-uk, チョ・ヒウク)는 임시입니다. 작가에게 확인하세요.
- **확인 필요:** 영어·일본어 문구, 특히 개인정보 안내와 결제 문구는 원어민 또는 법률 검수를 거치지 않았습니다.
- 문의 메일 본문의 항목명과 작품 캡처 속 글자는 한국어 그대로입니다.
