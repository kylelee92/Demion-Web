# Precision Works 콘셉트 메모

`sites/precision-concept`는 DEMION 포트폴리오용 **가상 기업** 콘셉트다. 사명, 주소, 전화번호, 설비, 사례는 모두 샘플이며 실제 기업이나 거래를 가리키지 않는다. 실제 기업의 이름, 인물, 연락처, 로고, 사진, 설비 정보를 넣지 않는다.
